# Pichigoose household

A shared household organizer for families: shopping lists, to-dos, notes and "who owes who", with a scrapbook look and Pichi the goose.

This is a web app first (React, TypeScript, Vite, installable on the home screen) with a Supabase backend.

## What's in here

- `docs/PRODUCT.md`: what the app does, the user stories, the screens and the build phases.
- `docs/DATA.md`: the database plan.
- `docs/DESIGN.md` and `docs/tokens.json`: the look.
- `docs/screens/`: hi-fi screens and wireframes.
- `assets/`: textures, the logo and Pichi.
